## Open the site

From this folder, open `Page/home.html` in a browser, or start Live Server on this folder and go to:

`Page/home.html`

The other pages are linked from the navigation bar.

| Page | File |
| --- | --- |
| Home | `Page/home.html` |
| About | `studentweb/about.html` |
| Projects | `Page/projects.html` |
| Contact | `Page/contact.html` |
| Services | Opens https://liyigarden.xyz |

The contact form keeps what you type in the browser, then returns to the home page. It does not send email.

## Express

The same pages are also available through Express. Install Node.js, then in this folder run `npm install` and `npm start`. Open http://localhost:3000

| Page | Address |
| --- | --- |
| Home | http://localhost:3000/ |
| About | http://localhost:3000/about |
| Projects | http://localhost:3000/projects |
| Contact | http://localhost:3000/contact |
| Services | https://liyigarden.xyz |
